# Expanding text box/button

A Pen created on CodePen.

Original URL: [https://codepen.io/sdaitzman/pen/bGbgPm](https://codepen.io/sdaitzman/pen/bGbgPm).

A search button which becomes the search bar when clicked on, reducing the need for space and looking great the whole time. Supports virtually all browsers and touch, looks great, and Apple sort of stole it a little bit for their recent redesign (okay, used very similar markup and CSS, probably by coincidence).
